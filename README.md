TITLE: PYTHON PORT SCANNER

OVERVIEW: This program is designed to scan through a user's IP address for any open port and out put both the port number and the service name of the port.

FEATURES: It outputs any open port in the ip address you provide with the range you set. All that is needed is your ip address and the range you want.

TECHNOLOGIES USED: Python, Socket, argparse

INSTALLATION:

USAGE: It is used to scan port of a user's ip address 

EXAMPLE OUTPUT: Port 135 is open and running epmap
                Port 139 is open and running netbios-ssn

WHAT I LEARNED: I learned how to use a function, return statement, argparse, sockets.
